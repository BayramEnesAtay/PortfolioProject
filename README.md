---

## 🎨 Design Philosophy (Neu-brutalism)
The frontend adopts a **Neu-brutalism** (Neo-brutalism) approach. This design trend emphasizes:
- High contrast colors (pastels mixed with stark black).
- Thick, pronounced borders (`border: 4px solid #000`).
- Sharp, hard-edged box shadows instead of soft blurs.
- Interactive micro-animations (shadows depressing upon click, buttons shifting to mimic physical depth).

## 🛠️ How to Run Locally

### Frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.
